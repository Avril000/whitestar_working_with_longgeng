### 卡片：每条字形记录长什么样

```json
{
  "id": "dbt-0042",
  "char": "山",
  "source_book": "多宝塔碑",
  "nature": "原碑拓本",
  "edition": "宋拓本",
  "source_holder": "故宫博物院藏",
  "src_url": "https://...",
  "src_page": "第 12 页 第 3 行 第 2 字",
  "image": "glyphs/dbt/0042.png",
  "verified": "已核对",
  "verified_by": "池裕斌",
  "note": ""
}
```

**四个要点**：

1. `source_holder` 写**馆藏机构**，不写"中华珍宝馆"（馆方明确要求）
2. `verified` 没核对过的一律写 **未核对**，不许默认打勾
3. `nature` 只要不是原碑拓本，就必须写 **后世临本**
4. `id`-千位开头认领。
   * 3 池裕斌
   * 0 吕博翰
   * 2 卢浩楠
   * 1 姚博乔
   * 4 李一虎
