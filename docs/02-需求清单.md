## 三、明确不做（写下来才管得住手）

| # | 不做 | 理由 |
| --- | --- | --- |
| N1 | **不做自动补字** | 库里没有就报缺，绝不静默生成或替换（红线） |
| N2 | 不做用户注册 / 登录 / 云端存储 | 与课题无关，徒增复杂度 |
| N3 | 不做手机端适配（优先保证电脑演示） | 汇报用电脑，精力集中在桌面端 |
| N4 | 不做多语言界面 | 中文即可 |
| N5 | 不做整页 OCR 识别 | 我们用人工标注 + 自动切字，不追求全自动识别 |

## 四、验收标准（怎样才算做完）

- [ ] 输入「江山如画」，能排出一条竖排条幅，字形来自真实碑帖
- [ ] 输入含库里没有的字（如「麟」），**明确提示缺字**，并给出 ≥2 种处理方案
- [ ] 点任一个字，能看到它的出处（碑帖名、来源链接、核对状态、核对人）
- [ ] 导出一张 PNG，能在画图里打开、能直接贴进 PPT
- [ ] 断网状态下，双击 `web/index.html` 完整跑通上述全部流程
- [ ] 字形库 ≥100 条，且管线脚本可一键扩充

## 五、给组员的脑暴引导（第 1 周任务 2 用）

请每人独立想，不用管能不能实现，重点回答这四个问题：

1. **你希望它长什么样？** 用文字描述界面，或者手画一张草图拍照。
2. **你会怎么用它？** 举个具体例子：你想集哪句话、想贴在什么地方、希望最后拿到什么（一张图？一份清单？）
3. **你最在意哪一点？** 是字形够不够真、排版够不够美、出处够不够清楚，还是操作够不够快？
4. **什么情况下你会觉得"这东西不行"？** 反面想一遍，往往能挖出最关键的需求。

> 想不出来很正常。去看看中华珍宝馆的集字功能（g2.ltfc.net），玩一玩，
> 然后问自己：**它哪里让你不满意？** 那些不满意的地方，就是我们作品的机会。
