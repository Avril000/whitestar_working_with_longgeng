### 三条长庚建议（请当场决定采纳与否）

1. **缺字要在预览区实时标出**（朱砂虚线框 + 角标），而不只靠弹窗提醒——一眼就能看出哪几个字是借的
2. **来源信息改成"点字看详情"**，比在底部堆一整段文字更清楚，也更省版面
3. 输入框与预览区**同屏可见**（边输入边看），不做滚动分区

## 三、数据模型：字形记录字段（草案，请当场拍板）

> 这是地基。字段名现在定好，后面改起来最贵。

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| `id` | 唯一编号 | `dbt-0042` |
| `char` | 单字 | `山` |
| `source_book` | 底本 | `多宝塔碑` |
| `nature` | **性质** | `原碑拓本` / `后世临本` / `集字本` / `拼合` |
| `edition` | 版本 | `宋拓本` |
| `src_url` | 来源链接 | 下载页面 URL |
| `src_page` | 出处位置 | 第几页 / 第几行第几字 |
| `image` | 图像路径 | `glyphs/dbt/0042.png` |
| `verified` | **核对状态** | `已核对` / `存疑` / `未核对` |
| `verified_by` | 核对人 | 组员名字 |
| `note` | 备注 | 疑问、争议 |

### 🔴 关于 `nature` 字段——这是本次组会最重要的一条

**临摹本里的字，不是颜真卿写的。**

课题原话：「绝不允许**悄悄**用其他来源的字冒充原帖」。
所以如果我们拿了后人临本的字，却在作品里当"颜真卿的字"展示——那就是冒充。

**规则：任何非原碑拓本的字，界面上必须可见地标记为「临」，元数据里 `nature` 必须如实填写。**

这不是可选项，是红线。做好了它反而是我们的卖点：
**我们是唯一一个告诉你"这个字不是真的"的集字器。**

## 五、长庚的优先级建议

```
1. 先让演示例句一定跑得通
   → 第一批字集优先覆盖高频成语用字
     （江山如画、厚德载物、宁静致远、天道酬勤…）
   → 别一上来就想建全库，那会拖死

2. 先做 P0 全部 + 缺字三方案
   → 这是课题点名要求的，也是得分主体

3. 再做 P1 里的对联模式 + 同字异形
   → 这两个最出彩

4. 最后才碰写法教程
   → 它最耗时、且不在课题要求内
```

## 六、验收标准（最终版）

- [ ] 输入「江山如画」，排出竖排条幅，字形来自真实碑帖
- [ ] 输入含缺字（如「麟」），**明确提示缺字**，且三方案都能走通
- [ ] 借来的字在画面上**一眼可辨**，点开能看到它来自哪个临本

- [ ] 导出 PNG 能在画图里打开、能直接贴进 PPT
- [ ] 断网状态下双击 `web/index.html`，上述流程全部跑通
