### 纸的宽窄与"重排后要重画"（2026-10-25 晚拍板的两条铁律）

⚠️ **纸不许被压得比字区还窄**：`.paper` 是 `.stage` 的 flex 子项，
`min-width` 必须是 `min-content`（＝内容最小宽），写死 190px 就会让纸被压窄、字溢出纸外。
对联是 `row-reverse`，溢出往**左**跑，正是滚动条够不着的一侧（看着像"顶出屏幕"）。
居中一律用 **自动外边距 `margin: 0 auto`**，不用 `justify-content: center`——
放不下时 auto 退化成 0，纸贴左边往右溢出，滚动条够得着（比 `safe center` 兼容性更老牌）。

⚠️ **凡是"按当时量到的坐标画死的东西"（版框 / 界行），纸一重排就得重画。**
诱因：开合抽屉改 `main` 的 padding-left、窗口缩放、放大对比、拖间距滑杆……
别在"渲染完""落款写完"这些时间点一个个补画（按下葫芦浮起瓢），
改由 `watchDecor()` 用 **`ResizeObserver` 盯住三张纸**（mainPaper / beforePaper / previewPaper），
尺寸一变就重画；没有 `ResizeObserver` 的环境退回 `window resize`，
抽屉那 0.22s 过渡再挂一次 `transitionend` 收尾。
> 💡 **"在若干时间点各补画一次"和"整幅滤镜"是同一类设计债**——
> 一个猜"什么时候会变"，一个猜"都会被反什么"，猜一次补一次，补到第五处必崩。
> 根治都是**盯住原因，而不是盯住时机**。

→ 统一成 `isBorrowed(rec, cfg)`，并立护栏：

- 全项目这个判定**只能有一处**（自检里数出现次数，注释里也不许写那个字面量）
- 收集落款文案那处必须走 `isBorrowed`
- 画虚线框那处也必须走 `isBorrowed`

> 这是「一个功能一个版本」的老教训换了个马甲：
> **改判定要改全，凡是判同一件事的两处代码，本来就该是同一个函数。**

### 落款改成按碑汇总一行（白星提：逐字列太长）

`其中 3 字借自《颜勤礼碑》` / 多碑时 `其中 5 字借自《颜勤礼碑》3、《九成宫》2`
——出处照样写得清清楚楚，但只占一行。

### ✅ 本句用字清单（白星要的入口）

点借字窗格里那句活提示展开，逐字列出：本碑的 / 借自哪块碑（含碑文第几字）/ 缺字。
朱笔顺手作为一个标签列进去——**没单独给朱笔做入口**（染红肉眼看得出，信息量为零）。

### ✅ 导出不画红框（白星拍板 2026-10-27，推翻了长庚原本的意见）

长庚原主张留（"屏幕和导出要一致"），白星否了，理由更硬：

> 我们的作品是用来生成集字碑帖的、是可以展示出来的。
> 如果导出的作品里有一个突兀的红框，那么这个借字功能导出的产物又能用在哪里呢？
> 我觉得这不是诚不诚实的问题——**我们的软件已经诚实了**，
> 但到了最后，如果用户自己假装看不到借了字，那是他自己的问题。
> 我们不能因为这种可能就把我们的输出搞的无法使用。

→ **规矩：编辑时明示，成品时干净。**
屏幕上有红框（编辑时得看清哪个是借的）；导出一律不画。
诚实性不靠红框，靠落款那句按碑汇总的借用说明。

> 长庚错在哪：把「有没有醒目提示」当成了「诚不诚实」。
> 诚实是"有没有说明出处"，红框只是让标记更醒目，属于**排版取舍**，不是道德问题。
> 而"一个没人能用的产物，功能等于白做"——这条比一致性重要得多。
> （同一个道理：Word 的修订标记编辑时满屏红字，接受后打印干干净净。）

### 一、好消息：最贵的一块已经做完了

- 悬停 tip 的借字说明文案——已有

所以**不用动导出、不用动 CSS、不用重踩反色**。剩下的是逻辑和 UI。

### 二、判定要改（这是根子）

现在 `borrowed` 判的是 `rec.nature !== '原碑拓本'`（临本/他碑/拼合）。
可两块碑**都是**原碑拓本，所以永远不会有 borrowed。跨碑借要看**碑**：

```
rec.nature !== '原碑拓本'  →  rec.book !== cfg.book
```

两处要改：`renderInto()`（屏幕加 class）和导出里的 `credits`（落款文案）。

### 三、开关做三档，不做一档（长庚意见，待白星拍板）

白星原设想：开关一开，所有字都能换成别的碑的写法（混搭）。

**长庚不同意"默认全开"**：
这个项目的卖点是**忠实一块碑**。默认随便混，"缺字如实留空、绝不造假"这条红线在观感上就软了——
汇报时老师随手一句「这到底是多宝塔还是拼的」，我们得答得上来。
但"有人喜欢混搭"也是真的（米芾本人就叫「集古字」）。

→ **折中做成三档分段按钮**（和"字色"同一套样式）：

| 档 | 行为 |
| --- | --- |
| `不借` | 关，现在的样子（**默认**） |
| `补缺` | **只有碑里没有的字才借**（推荐当默认档） |
| `混搭` | 有字也能换别的碑的写法，给要混的人 |

### 四、借哪块碑：数据驱动，不写死
