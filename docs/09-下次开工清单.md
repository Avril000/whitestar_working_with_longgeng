### 多版本选择（2026-10-21 做，当晚按白星意见改了交互）

同一个字在碑里往往出现很多次、写法各不相同：**之 22 版、塔 15 版、法 15 版、禪 12 版**，
一共 **195 个字**有多种写法。

**自动避复**：同一句里某个字第 n 次出现，默认就用第 n 种写法——
书法忌讳一幅里同字长得一模一样，系统自动绕开。
（想看效果就输「**道可道非常道**」：道出现 3 次、有 6 版，会自动给出 3 个不同写法）

角标三种状态，挂在字格右下角，点它展开全部写法：

| 角标 | 含义 |
| --- | --- |
| 黄点 | 还没挑（用的是自动避复给的版本） |
| 黄点带晕 | 挑过了但没拍板 |
| 绿点 | 拍板了，记在本机，下次打开还是它 |

面板两个按钮（白星 2026-10-21 定的）：

| 按钮 | 行为 |
| --- | --- |
| **选好了** | 就用这一版，收起面板，角标变绿 |
| **再想想** | 收起面板，改动留着，角标保持黄——方便先整体看一遍再回来定 |
| 恢复默认 | 丢掉选择，回到自动避复给的那一版 |

- 点一个写法主区域**立刻换，面板不关**，可以连着试
- 选择是**逐字**的（第 1 个「之」和第 2 个「之」可各选一版），键是 `碑:字#第几次`
- 记忆写在 localStorage：`glyph_pick_v1`（选了哪版）+ `glyph_pick_ok_v1`（是否拍板）
- **导出 PNG 尊重选择**——画的是你挑的那个版本
- 三个按钮都有悬浮说明（鼠标停一下就出来，和字格出处提示同一套样式）
- 演示句「上善若水 道法自然」里水(5) 道(6) **法(15)** 自(5) 然(5) 五个字带黄点

**手动避复的提示**（白星 2026-10-21 提的）：
版本面板里每个写法下面标着「本句**别处**还有几处用了它」——
标红的说明选了会撞成同字同形，鼠标停在红字上会告诉你撞在**第几个字**。
主区域也会兜底：万一手动挑成一样，撞了的格子套朱砂虚线框，
状态栏报「N 处同字同形」。这样收起面板之后也不会忘。

## 四、已经踩过的坑（持续补充）

| 坑 | 说明 |
| --- | --- |
| 别双击 `.py` | 用根目录的 `.bat` |

| **字形图要过调色板** | 墨色+透明只有两色，`quantize(32)` 后单张 9.9KB → 1.9KB，省 80% |
