## 〇、先回答那个小问题：`.py` 能双击吗？

**不能，也别试。**

三个原因，都很实际：

1. **没装关联**。`.py` 在你机器上默认没有"双击=运行"的关联，双击出来的是"选择打开方式"对话框。
2. **窗口会一闪而过**。就算跑起来了，程序跑完窗口立刻关掉——**你根本来不及看它报了什么错**。出了问题你只会看到黑框闪了一下，然后什么都没有。
3. **可能用到错的 Python**。我给你的脚本要用到 `pillow / numpy / scipy` 三个包，它们装在**隔离环境**里（`C:\Users\BOHAN LYU\.workbuddy\binaries\python\envs\default`）。双击时系统可能用另一个干净的 Python，直接报 `ModuleNotFoundError`。

所以我做了四个 `.bat`。**`.bat` 双击就是运行**，而且我让它跑完停住等你按键——不会闪退。

## 一、四个双击入口（放在项目根目录）

| 双击这个 | 它做什么 | 什么时候用 |
| --- | --- | --- |
| **`一键_出卡片包.bat`** | 页图 → 切字 → 总览图 → csv → 打包 zip | 有新页图要处理时 |
| **`一键_收卡片.bat`** | 组员填的 csv → 字形库 → 网页数据 → 报缺口 | 组员交回卡片后 |
| **`查12字缺口.bat`** | 只查演示例句那 12 个字凑齐没 | 随时，想到就查 |
| **`强制重切.bat`** | 把已切过的页全部重切一遍（旧结果先归档不删） | 只在你调了切字参数、想重来时 |

> 第一次运行如果弹出**"Windows 已保护你的电脑"**，点「更多信息」→「仍要运行」。
> 这是本地脚本的正常提示，不是病毒。

## 二、完整流程：一张图 → 组员的包

```
 ①你把页图丢进去        ②双击一个 bat          ③发给组员
 ┌──────────────┐      ┌──────────────┐     ┌──────────────┐
 │ data/processed │  →   │ 一键_出卡片包  │  →  │ dist/xxx.zip │
 │   01.png      │      │              │     │              │
 │   02.png      │      │  （中间全自动）│     │ 微信/QQ 传过去 │
 └──────────────┘      └──────────────┘     └──────────────┘
```

### 第 1 步：把页图放进 `data/processed/`

- 文件名必须是 **`01.png`、`02.png`、`03.png`** 这样——数字 + `.png`
- 数字就是我们的"页序号"，后面所有文件名都靠它串起来
- 图从哪来：中华珍宝馆截图 / PDF 转出来的页图（`tools/pdf_to_pages.py`）

> ⚠️ **页序号 ≠ 珍宝馆图号。** 珍宝馆图片是倒着排的，
> 我们的 `01.png` 对应珍宝馆图号 **34**。这个对应关系在 `data/pages_info.json` 里，
> 卡片的"珍宝馆图号"列就是从这儿取的。**换页了记得改这个文件**，不然出处全错。

### 第 2 步：双击 `一键_出卡片包.bat`

它会依次干这几件事，全程有中文提示：

| 顺序 | 动作 | 产出 |
| --- | --- | --- |
| 1 | 二值化、去朱红印章、列投影+连通域切字 | `glyphs_XX/crop/` 下的小图 |
| 2 | 拼一张带序号的总览网格图 | `glyphs_XX/card_sheet.png` |
| 3 | 生成 csv 卡片（一页一张） | `data/cards/卡片_XX页.csv` |
| 4 | 收进一个文件夹并压缩 | `dist/卡片包_日期.zip` |

**已经切过的页会自动跳过**（提示"已有 N 个字块，跳过切字"），不会覆盖你手工补的块。放心反复双击。

跑完窗口会停在 `Done. Send the zip in dist\ to your group.`，看一眼有没有红色报错再关。

### 第 3 步：把 zip 发给组员

`dist\卡片包_20261020.zip`，大约 4~5 MB，微信/QQ 都传得动。里面是：

```
卡片包_20261020/
├─ 填写说明.md          ← 组员先看这个
├─ 卡片_01页.csv
├─ 卡片_02页.csv
├─ 卡片_03页.csv
├─ 01页_字块总览.png     ← 认字就看这张，格子上的号=卡片序号
├─ 02页_字块总览.png
├─ 03页_字块总览.png
└─ 单字图/01、02、03/    ← 140 张单块图，看不清时放大看
```

组员只需要 Excel / WPS，**不用装 Python，不用碰任何脚本**。

## 三、收回来：组员交了卡片之后

### 第 1 步：把三张 csv 放回 `data/cards/`

- **同名覆盖**原来的文件（`卡片_01页.csv` 覆盖 `卡片_01页.csv`）
- **不要改名**，不要留成 `卡片_01页(1).csv` 这种
- 如果组员存成了 `.xlsx`，让他另存为 CSV 再发（Excel 会弹"是否保留此格式"，选「是」）

### 第 2 步：双击 `一键_收卡片.bat`

它做三件事：

1. **回填**：把 csv 里填的字、出处位置、核对人、备注写进字形库
   - 字和核对人都填了 → 状态「已核对」
   - 备注里写了"存疑" → 状态「存疑」
   - 字没填 → 保持「未核对」，不入库
2. **生成网页数据**：`web/data.js` + 把单字图同步到 `web/glyphs/`
3. **报缺口**：直接告诉你 12 个字齐了没

### 第 3 步：双击 `web/index.html` 看效果

不用起服务器、断网也能开。这就是汇报那天要演示的东西。

## 四、随时想查进度：`查12字缺口.bat`

输出长这样：

```
演示例句：江山如画 / 厚德载物 / 宁静致远
去重后共 12 个字

已有 8 / 12
  ✅ 江   01_r3_g02    第01页 第1行第3列  已核对/李四
  ✅ 山   02_r1_g05    第02页 第2行第5列  已核对/王五
  ...

还缺 4 / 12
  ❌ 画  厚  载  物

按句看：
  江山如画  ✅✅✅❌  还缺：画
  厚德载物  ❌❌❌❌  还缺：厚德载物
```

**改例句不用改程序**，只改 `data/goals.json`：

```json
{
  "sentences": ["江山如画", "厚德载物", "宁静致远"]
}
```

改完再双击一次就行。

## 五、目录约定（记住这张表就不会放错）

| 路径 | 放什么 | 谁维护 |
| --- | --- | --- |
| `data/processed/01.png` | 页图原图 | 你 |
| `data/processed/glyphs_01/crop/` | 切出来的单字块 | 程序 + 你手工补的 |
| `data/processed/glyphs_01/_rejected/` | 初筛剔除的块 | 程序 |
| `data/cards/卡片_01页.csv` | 待填 / 已填的卡片 | 组员 |
| `dist/` | 打包好的交付包（**不进 git**） | 程序 |
| `data/goals.json` | 演示例句 | 你 |
| `data/pages_info.json` | 页序号 ↔ 珍宝馆图号 | 你 |
| `web/` | 网页，双击 `index.html` | 你 |

**手工补字块的命名规则**：`页序号_H序号.png`，比如 `02_H04.png`，
直接丢进 `data/processed/glyphs_02/crop/`。下次跑 `一键_出卡片包` 会自动认出来，
卡片里标「手工」、总览图里标红底「手」。**不用登记，不用改任何配置。**

## 六、出错了怎么办

| 你看到的 | 意思 | 怎么办 |
| --- | --- | --- |
| `[ERROR] Python environment is not ready` | 隔离环境的 Python 找不到了 | 找长庚 |
| `[停] 找不到页图：04.png` | `data/processed/` 里没这个文件 | 检查文件名是不是 `04.png` |
| `[停] data/processed/ 里没有 01.png 这样的页图` | 一张页图都没有 | 先放页图 |
| `ModuleNotFoundError: PIL` | 用错 Python 了 | 别双击 `.py`，双击 `.bat` |
| 卡片条数比上次少很多 | 可能某页被重切坏了 | 去 `glyphs_XX/_stale/` 翻旧结果 |
| 组员填的字没进库 | 名字写错列 / 存成了 xlsx | 看 `一键_收卡片` 输出的"已填 N 条" |

**万一切坏了别慌**：`强制重切.bat` 每次都会把旧结果先挪到 `glyphs_XX/_stale/时间戳/`，
从不直接删。想找回哪个文件，从那儿拷回来就行。

## 八、这套东西为什么这么设计（给你讲透，汇报时可能用得上）

**为什么不干脆做个网页上传图片、一键切字？**
能做，但要服务器、要上传、要处理跨域。我们 11/05 就要汇报，把工程量花在演示效果上更划算。
切字是**组会时在你自己电脑上跑一次**的事，不需要做成产品功能。

**为什么卡片用 csv 而不是在线表格？**
csv 是纯文本：能进 git、能版本对比、程序零误差读回来、Excel 双击就能填。
在线表格要联网、要权限、导出格式还容易变。

**为什么切完还要"人工核对"这一道？**
拓本字口模糊，机器只能定位"这里有个字"，认不出"这是什么字"。
而且**认错字是硬伤**——汇报时老师指着一个错字问"这是颜体的'德'吗"，
比留个空格难看得多。所以我们的红线是：**库里有就必须有出处、有核对人、有状态。**

**为什么"存疑"要单独一个状态？**
因为我们不确定的东西要**敢说不确定**。网页上会显示黄色角标，
老师问起来你能坦然说"这个字风化严重，我们标了存疑"——这是加分项，不是扣分项。
