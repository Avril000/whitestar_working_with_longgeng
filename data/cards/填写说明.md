# 卡片填写说明（一页看完就能开工）

> 这一轮按**页**发放，你手上这一包 = 一页，里面有该页全部字块。
> 不用装任何软件，Excel / WPS 双击打开就能填。
> 2026-10-21 更新：改用**单字图**核对，不再发总览图。

## 一、包里有这三样

| 文件 | 作用 |
| --- | --- |
| `卡片_XX页.csv` | 这一页的核对表，一页一份 |
| `单字图\XX_G01.png …` | **每一个字块的图**，文件名和卡片「图片文件」列一一对应 |
| `填写说明.md` | 就是这份 |

**怎么对照**：看卡片最后一列「图片文件」（写的是 `crop/10_G01.png`），
取文件名 `10_G01`，就去 `单字图` 文件夹里找 `10_G01.png`。
**你看到的这张图，就是最终会放进网页、导出作品的那一张**——
所以你核对的就是真正要用的东西，不用担心对不上号。

> 图是从碑刻拓片上切下来、再翻墨处理过的：宣纸底、墨色字，和最终成品一致。

## 二、你只需填 1～2 格

表格里 14 列，**长庚已经预填好了 10 列**，包括：

- **「字」列已预填**（读自《多宝塔碑》释文，按碑文顺序一一对应）
- **「出处位置」已预填**（写成 `碑文第1031字`，不用你数行列）

你要做的是：

| 列名 | 怎么填 |
| --- | --- |
| **字（必填）** | 已预填。**对着单字图看一眼**：图和这个字对得上 → 不用动；对不上 → 改成正确的字，并在备注说明 |
| **出处位置** | 已预填，**别改** |
| **核对人（必填）** | **填你的名字**（这列必填，程序靠它判定"已核对"） |
| **备注（选填）** | 有问题才写，见第四节 |

一句话：**看图 → 字对不对 → 对就填名字，不对就改字 + 备注**。

## 三、在 Excel 里怎么填得快

名字这一列，三种都能用，**推荐第一种**：

1. **双击填充柄**：第一格打好名字，选中它，双击格子右下角的小方块 → 自动填到底
2. **Ctrl + D**：选中一整片区域（首格已填好），按 `Ctrl + D` 向下填充
3. **Ctrl + Enter**：选中一片区域，输入名字，按 `Ctrl + Enter` 全部填入

这三种都不会破坏表格结构，长庚的程序能照常读回来。

### ⚠️ 三个会踩的坑

**坑 1：保存时别存成 `.xlsx`**
按 `Ctrl + S`，Excel 会弹"是否保留此格式"——**选「是」/「保留」**。
存成 `.xlsx` 长庚的程序就读不到了，得你手动再导一次。
（不放心就另存为「CSV UTF-8(逗号分隔)」，这个最稳。）

**坑 2：别插列、别删列、别改表头文字**
前 6 列的列序和名字都别动。后面 8 列是来源信息，改了会让出处出错。

**坑 3：出处位置别手改成 `3行2列` 之类**
这次的位置是"碑文第 N 字"，统一口径，改了反而乱。

## 四、备注写什么

| 情况 | 备注怎么写 |
| --- | --- |
| 字和图对得上，确定 | 留空 |
| 图上看不清 / 拿不准 | 写 `存疑：可能是「X」或「Y」` |
| 完全认不出（残损） | 写 `认不出` |
| 字块切坏了（半个字、两字粘连、白块） | 写 `残块` / `粘连` / `废格` |
| 预填的字明显不对，你改了 | 写 `改：原「X」→「Y」` |

> 备注里写「**存疑**」，程序会自动把这条标成"存疑"状态，
> 汇报时网页上会显示出来——**诚实比好看重要**，这是我们项目的红线。
> 认不出的字别硬猜，留空或写存疑都比猜错强。

## 五、填完怎么办

把 csv **原样发回**（**别改名**，比如 `卡片_10页.csv` 就叫这个名字），长庚会跑程序：

1. 回填进字形库
2. 重建网页数据（字形图是内嵌的，双击 `web/index.html` 就能看）
3. 统计还差哪些字

---

*有认不出的字别硬猜。认错一个字，汇报时被老师当场指出来，比空着难看得多。*
