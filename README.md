# 碑帖集字生成器

> 移动信息化 · 课堂研讨 · 课题 19
> 输入一句话，从已标注的碑帖字形库里取出对应单字，排成条幅 / 对联。
> **库里没有的字，如实报「缺字」——绝不用其他来源的字冒充原帖。**


## 三条红线

1. 字形库里没有的字，**必须报缺字**，不能静默替换、不能留空不提示。
2. 每一条字形数据，**必须标注来源与核对状态**；未经人工核对的，一律标「未核对」。
3. 演示必须**真跑通**，不录屏、不造假。
