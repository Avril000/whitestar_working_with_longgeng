# 碑帖集字生成器

> 移动信息化 · 课堂研讨 · 课题 19
> 输入一句话，从已标注的碑帖字形库里取出对应单字，排成条幅 / 对联。
> **库里没有的字，如实报「缺字」——绝不用其他来源的字冒充原帖。**

| 项目 | 内容 |
| --- | --- |
| 队伍 | 白星小组（5 人） |
| 汇报日期 | 2026-11-05 |
| 目标档位 | **挑战层（优秀）** |
| 协作方式 | 白星与长庚主笔产出 → 队长审核 → 同步至 GitHub |

## 它现在长什么样

两块碑、三千多条真拓本字形，拼进一个**双击就能开、断网也能跑**的网页里。

| 指标 | 现状（2026-10-28） |
| --- | --- |
| 字形库 | **3459 条 / 1193 字**（多宝塔碑 2001 + 颜勤礼碑 1458） |
| 已核对 | 3458 条（1 条存疑，如实标注） |
| 多版本字 | 593 个（「之」就有 57 种写法，可自动避复、也可逐字手挑） |
| 网页体积 | `web/` 整个目录，其中 `data.js` 约 11.5 MB（字形图 base64 内嵌） |
| 前端自检 | **279 项**（`node tools/verify_web.js`，改前端后必跑） |
| 构建脚本 | 21 个 Python 脚本（`tools/`）+ 7 个双击 `.bat` |

## 日常怎么用（一句话版）

> **`.py` 不要双击**（会闪退、还看不到报错），**双击 `.bat`**。

| 场景 | 双击 |
| --- | --- |
| 有新页图要切字、出卡片 | 往 `data/inbox/` 放图 → **`一键_投递制卡.bat`**，答完自动出包 |
| 想按人分组发活 | **`一键_分组.bat`** |
| 组员交回填好的卡片 | 三张 csv 覆盖回 **`data/cards/回收/`** → **`一键_收卡片.bat`** |
| 想知道 12 个字还缺几个 | **`查12字缺口.bat`** |

完整流程、目录约定、报错对照表见 **[docs/08-操作手册.md](docs/08-操作手册.md)**。

## 怎么运行成品

不需要安装任何东西：

1. 进入 `web/` 目录
2. 双击 `index.html`

（离线可用，不依赖网络、不依赖 Python、不依赖任何外部库。）

## 网页上能做什么

**集字调整**抽屉共 **6 项**：样式 / 成册 / 间距 / 遮罩 / 朱笔 / 借字。

| 项 | 能调什么 |
| --- | --- |
| 样式 | 条幅 / 对联、墨色 / 朱砂 / 原碑拓片观感、落款、印章（可换成自己的印） |
| 成册 | 界行（乌丝栏 / 朱丝栏）、版框（文武 / 单边）、排列方向 |
| 间距 | 字距、行距、页边距，三档预设 + 滑杆 |
| 遮罩 | 田字格 / 米字格 / 九宫格，临帖辅助线 |
| 朱笔 | 点字染朱砂，标重点、标要练的字 |
| 借字 | 三档：**不借**（默认）/ **补缺**（只补本碑没有的）/ **混搭**（把别碑写法也列出来挑） |

改设置走**草稿机制**：面板里改的是预览，**点【应用改动】才落到纸上**，
关面板不丢草稿，随时能【放弃】。

导出 PNG = 拓本墨字 + 界格 + 落款 + 朱砂印章，直接交作业。

## 三条红线

1. 字形库里没有的字，**必须报缺字**，不能静默替换、不能留空不提示。
2. 每一条字形数据，**必须标注来源与核对状态**；未经人工核对的，一律标「未核对」。
3. 演示必须**真跑通**，不录屏、不造假。

> **不做「偏旁拼字」**：把两个字的部件拼成一个新字，本质是造字。
> 缺字只走两条路：留空，或借他碑真迹（且默认不借）。

## 目录结构

```
whitestar_working_with_longgeng/
├─ 一键_投递制卡.bat       ← 双击（推荐）：往 data/inbox/ 放图，问答式一条龙
├─ 一键_出卡片包.bat       ← 双击：页图 → 切字 → 卡片 → 打包给组员（老入口）
├─ 一键_收卡片.bat         ← 双击：回收区的 csv → 字形库 → 网页数据
├─ 一键_分组.bat           ← 双击：按人数均分卡片
├─ 查12字缺口.bat          ← 双击：查演示例句的字凑齐没
├─ 强制重切.bat            ← 双击：全部重切（旧结果先归档，不删）
├─ 一键_部署到服务器.bat   ← 双击：传 web/ 到班级服务器（副轨，需外网）
├─ README.md              本文件
├─ docs/                  全部文档（需求、选型、数据、分工、时间线、操作手册）
├─ data/
│  ├─ inbox/              ⭐ 投递箱：这一轮要做什么就往这放，做完自动归档
│  ├─ raw/                原始碑帖大图（不进仓库，见 .gitignore）
│  ├─ cards/              待填 / 已填的卡片；⭐ 只有「回收/」子目录会被读进库
│  ├─ metadata/           碑文释文、底本登记表、剔除清单
│  ├─ goals.json          演示例句（改这里就能换例句）
│  ├─ pages_info.json     页 ↔ 碑 / 珍宝馆链接 / 馆藏（向导自动登记）
│  └─ processed/          中间产物：页图 + glyphs_XX/（crop 单字块 + meta 真身）
├─ tools/                 Python 构建脚本（自动化管线，只在自己电脑上跑）
├─ web/                   前端成品（零依赖，双击 index.html 即可运行）
├─ dist/                  打包好的交付包（不进仓库）
├─ presentation/          汇报 PPT、演示脚本
└─ _archive/              版本快照（每跑通一个功能存一份）
```

## 技术选型（一句话）

**方案 C：构建期 Python，运行期纯前端零依赖。**

字形库、切图、打包全在**自己电脑上**用 Python 跑一次，产出一个自包含的 `web/` 目录；
运行期没有任何后端、没有任何网络请求，**双击 `index.html` 就是全部部署动作**。
代价是 `data.js` 大（11.5 MB），换来的好处是：汇报现场断网、没 Python、没服务器，都照样演示。
